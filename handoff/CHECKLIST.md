# 接入检查清单

对照在线演示，在实际 App WebView 中检查样式与交互。

## 资源与样式

- [ ] `node scripts/check-delivery.mjs` 通过，图片、SVG和字体无丢失、无意外改动。
- [ ] 字体网络请求成功且实际加载 `BatteryGuardianDIN`，不是仅声明了 font-family。
- [ ] 普通中文使用系统字体；表格和坐标轴使用系统字体，坐标文字10px/400。
- [ ] 375/393px及320px窄屏无横向溢出；最大宽550px，外围无模拟手机圆角。
- [ ] 白卡间距8px、圆角16px、无投影；静态数据模块内容内边距12px、两行间距12px、底部三列高度44px。
- [ ] 宿主按钮、字体、body间距等没有被报告全局样式覆盖。
- [ ] 手机点击后无意外焦点外圈，状态标签和车辆选中态保留。

## 抽屉

- [ ] 首次打开与重复打开都有向上滑入动画，无直接闪现。
- [ ] 点击关闭、点击遮罩、选择车辆/体检单、点击“我知道了”都能正常关闭。
- [ ] 退出动画完成后才移除/卸载，关闭动画不被业务条件渲染截断。
- [ ] 遮罩纯黑60%，无模糊；顶部无手柄，圆角20px、padding16px。
- [ ] 在页面中部打开，滑动遮罩时底层位置不变。
- [ ] 长内容可以独立滚动，到顶/到底继续滑不会穿透到底层。
- [ ] 关闭后准确恢复原浏览位置，页面能继续正常滑动。
- [ ] 连续快速打开/关闭，旧回调不会关闭新的抽屉。
- [ ] 路由卸载调用 `destroy()`，页面不遗留 fixed/overflow 隐藏或重复事件。

## 数据替换后

- [ ] 三种安全状态、长车型名称、缺失字段不会破坏布局。
- [ ] 静态数据随车辆切换；标称续航与预计续航独立，缺失时显示“-”且隐藏单位。
- [ ] “X项需关注”与当前展示的关注+严重数量一致，零项隐藏。
- [ ] 车辆及体检单仅一条时入口不显示为可切换；无数据按正式业务空态处理。
- [ ] 同车型对比默认前三条，排名区域始终显示；展开/收起文案及箭头同步。
- [ ] 专业分析默认折叠，展开/收起动效和三张独立数据卡保留。
- [ ] 替换成自己的图表后，Tab、图例、边框、坐标和均值线与规范一致。
- [ ] 图表展开及屏幕旋转后尺寸正确，没有裁字或挤压首尾横轴标签。
