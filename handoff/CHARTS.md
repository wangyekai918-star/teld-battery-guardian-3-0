# 图表视觉规范

数据与绘图实现由前端负责。`js/chart-theme.js` 提供 `window.BatteryGuardianChartTheme`，仅包含视觉参数。它不是 ECharts option，也不会绘制图表；可映射到 ECharts、Canvas、SVG 等实现。

## 通用要求

- 坐标轴：系统字体10px、常规字重，不使用 D-DIN。
- 图例：系统字体11px、常规字重，与14px加粗 Tab 分开层级。
- 非中文数值单位按字段显示，不把未提供单位的数据自行转成百分比。
- 挂载后、容器尺寸变化及展开折叠区域后，让图表重新计算尺寸。
- Canvas 需要显式配置字体、颜色和线宽；外部 CSS 无法自动影响画布文字。
- 缺失数据用空态，不用0、正常或其他车辆曲线补齐。

## 充电曲线

外层结构沿用 `.curve-tabs`、`.curve-panel`、`.curve-meta`、`.curve-legend` 和 `.curve-plot`。Tab 与图表间距0；图表外框1px `#EFF5F7`，圆角10px、内边距10px。

| 属性 | 值 |
| --- | --- |
| 绘图区整体高度 | 212px |
| plot inset | 左30、右16、上18、下34px |
| 实际电流 | `#00BDA1`，2px，圆头 |
| 需求电流 | `#F27D78`，2px，圆头 |
| 坐标文字 | `#8B9A9F`，系统10px/400 |
| 网格 | `#E2EAED`，0.5px，虚线3/4 |
| 横轴 | 5个标签，使用同一时间比例尺，中心等距，留足首尾半个标签宽度 |
| 图例 | 常规11px，条目间距12px |

默认 Tab 是电流曲线。线上演示的电流走势是模拟序列；其他五个 Tab 的空图是演示范围，不限制正式项目接入真实数据。

## 专业分析

每项默认折叠，展开后3张独立白色数据卡，外侧及彼此间距8px。图表白底，无外围描边。

| 属性 | 值 |
| --- | --- |
| 图表整体高度 | 168px |
| plot inset | 左35、右13、上14、下26px |
| 本车 | `#F27D86`，实心点半径2.6px |
| 同城同车型 | `#00BDA1`，线宽1.8px，白底空心点半径1.7px、描边1.2px |
| 网格 | `#EFF3F5`，1px，虚线3/3 |
| 各自均值线 | 对应序列颜色、线宽1px、虚线4/3，本车透明度0.7、同车型0.5 |
| 均值图例 | 24px宽，左半红色虚线、右半绿色虚线 |

不要复用 `demo/data.js` 中的 `bounds/trace/own` 作为数据源：这些是截图复绘坐标。正式图表应从真实时间和测量值建立坐标轴。
